No account. No sign-in. Nothing leaves your browser.

Sweep never asks for inbox access, because it never needs it — everything happens on the page in front of you.

✓

No OAuth, no inbox access

Other cleanup tools connect to your mailbox on a server somewhere. Sweep can't — it has no server and asks for no account.

✓

Zero network requests

Your mail is never read, copied, uploaded or analysed. There is nowhere for it to go.

✓

One permission, for one thing

Storage — used only to remember your filter choices between visits, on your own machine.

✓

Deletes go to Trash

Gmail's own Delete button, so everything is recoverable for 30 days. Sweep never empties Trash.

★

Open source — read every line before you install it
